# ALU Back-End

## 0. Gather Data from an API

This project contains a Python script that retrieves an employee's TODO list from the JSONPlaceholder REST API and displays the employee's completed tasks.

### Usage

Run the script with an employee ID:

```bash
python3 api/0-gather_data_from_an_API.py 2
```

The script displays the employee's name, the number of completed tasks, the total number of tasks, and the titles of completed tasks.
